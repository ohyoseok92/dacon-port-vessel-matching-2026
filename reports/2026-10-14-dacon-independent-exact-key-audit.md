# DACON 독립 가설 검증: 학습부 복합키의 단일 정답 매핑

2026-10-14. 공식 제공 `train.csv`만으로 호출부호가 겹치지 않는 네 개의 80:20 분할을 만들었다. 각 분할의 학습부에서만 `선명 정규화(NFKC·공백 제거·소문자화) + 총톤수 + 국제총톤수 + 국적 + 선종`을 정답 ID에 매핑했다. 한 키에 정답이 여러 개면 사용하지 않는 규칙이다. 검증부 정답은 매핑에 넣지 않았다.

| 분할 시드 | 검증부 복합키 적중 | 그중 한글 선명 | v5 예측 변경 |
|---:|---:|---:|---:|
| 42 | 0 | 0 | 0 |
| 43 | 0 | 0 | 0 |
| 44 | 0 | 0 | 0 |
| 20261013 | 0 | 0 | 0 |

복합키가 전혀 적중하지 않으므로 기존 v5 합본의 로컬 가중 정확도 **0.981500 / 0.989011 / 0.981541 / 0.995106**은 이 규칙을 적용해도 그대로다. 이름 단독 및 이름+총톤수로 완화해도 네 분할에서 적중은 모두 0건이었다. 공식 학습에서는 같은 선명이 다른 호출부호에 반복되는 사례가 없기 때문이다. seed44의 `마스그라치` 두 행은 같은 호출부호에 묶여 함께 검증부로 이동한다. 정답 카탈로그 `Marsgracht`와 오답 후보 `Maasgracht`는 이름 외 총톤수·선종·국적·규모가 같다. 이 복합키만으로는 해당 오답을 구제하지 못한다.

결론: **이번 가설은 배제한다.** 공식 테스트에 학습 선명이 재등장할 가능성 자체를 부정하는 것은 아니지만, 호출부호 미관측 상황의 네 로컬 검증에서 개선 증거가 없다. 새로운 제출 ZIP에 적용하지 않았다. 공식 테스트 정답, 외부 선박 DB, 다른 테스트 행의 집계는 사용하지 않았다.
